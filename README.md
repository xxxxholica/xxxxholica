## [kikimimi](https://github.com/xxxxholica/kikimimi)

Google Cloud TTSとDiscord APIを用いた読み上げボット。

- 運用開始: 2025年3月
- 規模: 利用者約20人
- ボイスチャンネルの入退室に連動した自動接続・切断
- 読み上げと音楽再生の同時利用
- ローカルでの音声生成から、応答速度を優先してGoogle Cloud TTSへ移行
- 無料利用枠を超えない自動停止ガード
